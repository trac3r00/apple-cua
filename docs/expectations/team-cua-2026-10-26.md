# Team CUA expectation contract: many hands, one team

Status: active plan (2026-10-26). Source: user request — "팀끼리 서로 편집하는
느낌으로, 서로 각자 알아서 할거 정해서 빨리 한다"; keyboard goes where the
keyboard is needed, clicks fire in parallel by the count needed, menus and the
Dock and the menu-bar apps and Control Center must be handled, and the primitives
humans use (drag, drag & drop, shapes, arrows, emoji, pasting a web image) must
work — fast, on Excel/Word/Keynote-class apps, without overlapping; when overlap
is required, wait for each other or skip and come back.

## What already exists (built and measured)

| Capability | Where | State |
|---|---|---|
| Keyboard + pointer + vision parallel lanes with resource policy | `run_hands` (HandsCoordinator) | done; overlap measured, no overlap by default on shared focus |
| Vision without a per-call capture | hot-session frame refresher | done; p50 24 ms warm, 300 ms freshness label |
| Input without the post-action read | deferred outcome | done; click 122 ms, type 132 ms |
| Multi-app parallel crews | `manage_workers` + WorkerCoordinator | exists; one worker per app |
| App menus (File > Save, Edit > Select All) | `invoke_menu` step + `invokeMenu` (core) | exists |
| Clipboard write + paste | `clipboard_write` step + core pasteboard | exists |
| Drag, drag & drop | `drag` step (pointer route) | exists |
| Stop switch across processes | file-backed `~/.apple-cua/stop.json` | exists |
| Jev decision kernel (per-step fan-out) | `run_decision` tool + `packages/agent` | wired this release; needs a live endpoint |
| Cross-process input serialization | `InputLock` (`~/.apple-cua/input-lock.json`) | new this release |

## The gaps this contract commits to close

1. **Menu-bar apps, Dock, Control Center** (top-right status items): they are
   separate processes (Control Center is `com.apple.controlcenter`, discoverable;
   Dock is `com.apple.dock`). Build one status-item/dock pressing path that
   enumerates the extra menu bars and presses through AX, verified against
   Control Center Wi-Fi and a Dock item launch.
2. **Office toolbars (Excel, Word, Keynote)**: their ribbon controls are AX
   buttons, so `run_hands`/`run_decision` can press them, but the labels are
   verbose. Build an office-specific space extension (toolbar groups as first
   class targets) and a scenario suite: set bold in Word, set a cell value and
   fill in Excel, insert a shape in Keynote.
3. **Shapes, arrows, emoji, web image paste**: shape/arrow = toolbar press +
   pointer drag across the canvas (two lanes already exist); emoji =
   clipboard_write + Cmd+V; web image = fetch bytes → clipboard image → paste.
   The pasteboard needs an image-capable write exposure in the step set.
4. **Crew planning**: the big model writes the crew plan (who does what, which
   app, which order); `run_decision` (Jev) steps each worker; `run_hands` gives
   each worker parallel hands; `manage_workers` assigns one worker per app. The
   overlap rule is the HandsCoordinator resource rule, generalized: never two
   writers on one window; a worker that would overlap waits, or skips and
   returns when the resource frees.
5. **Perceived startup slowness**: the MCP server is persistent, so "밥 먹고
   와도" latency is dominated by first-observation settle and model round trips,
   not process startup. The hot-session refresher plus deferred outcomes remove
   the per-call captures and reads; the remaining budget goes to the decision
   kernel (Jev) which answers in sub-seconds.

## Safety invariants (unchanged)

Observation tokens, preflight per step, window guard, stop switch (machine-wide),
input lock (machine-wide), no replay of an uncertain action. A crew is still one
team on one machine: the input lock serializes physical events, and the risk
gate keeps sends/publishes/deletes behind the same approval rules.

## Done when

T1-T9 pass on the real apps with measured wall times under the interactive
budgets (input-only <= 200 ms, vision <= 300 ms, a full crew scenario reported
with its own timing), and T10 demonstrates the wait/skip-and-return rule.
