Base: `ae5455d` (PR #22). The original dirty checkout was based on `7f4e0f8`.
Three-way reconciliation retained the newer isolated-desktop fixes and Bun
migration already on main. This release adds the remaining history work,
permission guidance, browser skill rename, and previously uncommitted evidence.
The generated `.senpi/html-pages/` report is local-only and is not included.

## Local checks

- All six TypeScript packages built with `pnpm -r exec tsgo -p tsconfig.build.json`.
- Production and test typechecking passed.
- Repository-wide Biome and shellcheck passed.
- 191 history, native offline, CLI and MCP tests passed across 23 files in one
  `bun test --isolate` run.
- 174 browser, preflight and test-support tests passed across 12 files.
- All three native helpers rebuilt for arm64 and x86_64, targeting macOS 15.
  Source hashes were regenerated with the binaries. These isolated-worktree
  builds are ad-hoc signed; the installed helper and its grants were not changed.
- `git diff HEAD --check` passed.

The native regression harness includes the real Objective-C implementation but
replaces event-tap creation and UI construction. It never starts NSApplication,
installs input monitoring, or queries the user's foreground application.

## Defects found before publication

- Retention threw on short unrelated directory entries. Canonical-name and
  real-directory checks now preserve unrelated files, malformed names and
  symlinks. The original native regression run had two failures; the fixed run
  passed.
- Recorder startup discarded saved pause state. Pause now survives restart.
- launchd's unconditional KeepAlive restarted an intentional menu Quit.
  A regression failed before the fix; the parsed plist now restarts only after
  an unsuccessful exit.
- Native capture ignored URL/private-browsing exclusions. Five offline cases
  reproduced the bypass. Unsupported policies now block capture and report the
  reason, including the default policy. A sixth case verifies policy revocation
  pauses an active recorder. This does not implement URL/private classification.
- Thirteen new test files still imported Vitest after upstream moved to Bun.
  Imports were migrated, five strict index-access errors were corrected, and
  the capture-error test now awaits its error callback instead of event-loop timing.

## Gate-review corrections

The initial independent review rejected four concrete integration/lifecycle
defects. All were reproduced before correction:

- A real `HistorySegmentStore.recordSuppressed()` created metadata without an
  event file and broke the timeline. The reader now treats a validated zero-event
  segment as empty while still rejecting missing nonempty evidence.
- The native timer did not expire history during paused or idle periods.
  It now prunes independently of capture. An offline fixed-clock timer test
  preserves the exact retention boundary and removes the expired segment.
- Successful service shutdown left persisted state as running. Both loaded and
  already-unloaded shutdown now persist stopped; a failed bootout preserves
  running state and the registration.
- Full uninstall left the history login service behind. It now checks ownership
  and rechecks the registration before stopping it, ahead of process/helper
  teardown. A failed stop aborts teardown; another checkout's service and grants
  are retained. Recorded activity and summaries are deliberately retained and
  reported in the uninstall plan.

The first three regression files had four failing tests before the fixes and
31 passing tests afterward. The uninstall regression run had three failures
before the fix; uninstall plus adjacent lifecycle tests then passed all 24.
The final 191-test run includes these regressions. Native binaries and input
hashes were rebuilt after the timer fix.

The follow-up review cleared the first three findings and caught a stale PID
after successful history shutdown: process teardown reported `kill ESRCH` as a
partial uninstall. A faithful stopped-process fake and an exit-race case both
failed before correction. Teardown now skips exited processes and accepts only
ESRCH from a concurrent exit; EPERM remains a failure. All 26 uninstall/lifecycle
tests passed afterward, followed by the CLI build, test typecheck and full Biome.

## Node source-entry CI correction

The first remote run passed preflight but each macOS target reported 21 CLI
failures: Node's type-stripping runner could not resolve `history-commands.js`
from the source entry point. The new history modules lacked the source-only
bridges already used by the other CLI modules. Eight matching bridges now cover
both eager and lazy imports; emitted package modules are unchanged.

Two new regressions exercise disabled digest and loopback UI startup/shutdown
through real Node. Both failed with the lazy bridges absent and passed with
them restored. Four existing help/version cases and the terminal configuration
case also passed. This verification used the real installed Node 26 binary via
an explicit PATH, not the session's Bun-backed `node` shim; CI uses Node 22.
The CLI build, test typecheck and repository Biome passed after this correction.
